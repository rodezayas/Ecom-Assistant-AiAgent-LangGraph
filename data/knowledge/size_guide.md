# Size Guide

## T-Shirts

Choose your usual size for a regular fit. If you prefer an oversized look, go one size up.

## Pants

If you are between sizes, choose the larger size for a relaxed fit and the smaller size for a tailored fit.

## Jackets

Pick your normal size if you plan to wear light layers. Go one size up if you want room for hoodies or sweaters.

## Shoes

Choose your normal shoe size. If you are between sizes, go up for running shoes and stay true to size for sandals.
